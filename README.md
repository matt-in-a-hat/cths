# Riverlution Tiny House Village

## Website for cths.nz

Built using Jekyll and deployed via a GitHub Actions workflow (`.github/workflows/pages.yml`) to GitHub Pages — just push to `gh-pages` and it builds and deploys automatically, no local build step required.

Changes can be made via an issue or pull request here, or by [contacting us](https://forms.gle/6v43PrYjfSCB77736).
